Portfolio Strategy · Working Prototype

Where to bet next: make the R&D portfolio trade-off explicit before the debate starts

Jane Natividad  ·  jane-natividad.github.io  ·  View on GitHub

Every early-R&D leadership team runs some version of this call: with finite discovery capacity, how much goes to a hot, fast-moving area versus doubling down where you already have platform depth? There usually isn't one right answer — there's a right answer for a given set of priorities. This tool doesn't pick a winner. It makes the trade-off visible, shows how fragile the current #1 is, and tells you exactly which priority shift would change the answer.

3 · How robust is the #1 pick?

For each criterion, the smallest single weight change that would put a different bet on top — the question a portfolio committee should ask before trusting a ranking.

    4 · The scores behind it (editable)

    0–10 judgement scores per bet. Change any one to see how much a single contested score moves the outcome.

    Design choices
    1
    Agree the weights, then the rankingThe scores are fixed judgement calls; what moves is how much leadership values each criterion. Getting research, finance, and commercial to agree on weights first turns "my program vs. yours" into "what are we optimizing for?"
    2
    Robustness is a first-class outputA ranking that flips with a 3-point weight change is a coin toss dressed up as analysis. The robustness check says so out loud.
    3
    Fully deterministicNo model in the loop. Every position traces to a score and a weight you can see and change.
    "Slide 'unmet need' to the top and the slow, hard bet wins. Slide 'speed to proof-of-concept' up and the calculus flips. Neither is wrong. The job isn't finding the answer — it's getting everyone to agree on the weights before the debate starts, so the ranking is trusted, not argued with."
    Prototype with illustrative data. The four therapeutic bets reflect broadly known industry dynamics; the 0–10 scores are directional judgement calls made for demonstration, not any organization's internal data.
